# Sales & Revenue Analysis

## Project Overview
This project analyzes sales data to understand revenue trends, profitability, regional performance, and product performance using Excel, SQL, and Power BI.

## Tools & Technologies
- **Excel:** Data cleaning and preparation
- **SQL (PostgreSQL):** Data querying and sales analysis
- **Power BI:** Interactive dashboard and data visualization

## Key Metrics
- Total Sales
- Total Profit
- Monthly Sales
- Monthly Profit
- Regional Sales and Profit
- Sales by Segment

## Analysis Performed
- Cleaned and prepared sales data using Excel.
- Used SQL to analyze sales, profit, monthly trends, regional performance, and customer segments.
- Developed a Power BI dashboard to visualize key performance indicators and business trends.

## Key Findings
- **Total Sales:** 32,480,984
- **Total Profit:** 1,240,093

## Conclusion
This project demonstrates the use of Excel, SQL, and Power BI to analyze sales performance, evaluate profitability, and present business insights through interactive visualizations.
